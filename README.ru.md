# toon-skills

[English version](README.md)

Скилы для Claude Code, чтобы делать консистентный мультсериал в связке **Claude Code**, **Higgsfield Seedance 2.5**, **Blender** и **Archcore**.

- **Blender строит план кадра:** кто где стоит, какого он размера, что делает камера, где склейки.
- **Seedance рисует игру персонажей:** по листам персонажей, фонам локаций и промпту с таймкодами.
- **Archcore сам ведёт документацию серии по ходу работы.**

## Зачем

Если отдать видео раскладки из Blender в Seedance как референс, модель копирует движение болванок. Герои скользят, двигаются как роботы и криво держат предметы. Если отказаться от Blender, пропадает план: герои телепортируются между склейками, плывут масштаб и перспектива.

Ключевой кадр на каждый шот тоже не спасает. Стартовый кадр запирает позу и камеру: персонаж не может развернуться, камера не может поехать. Каждый план стоит отдельной генерации картинки, а с первого раза она получается редко. Минимум Seedance в 4 секунды съедает деньги на коротких планах.

Поэтому работа разделена:

| Источник | Что несёт | Чего не несёт никогда |
|---|---|---|
| Видео-референс из Blender, персонажи в нём заменены цветными **капсулами** | движение камеры, склейки, крупность, позиции, траектории, масштаб, предметы | руки, ноги, позы, игру |
| Листы персонажей и фоны локаций, делаются один раз на сериал | как выглядят персонажи и места со всех сторон | позиции |
| Промпт с таймкодами | кто что делает в каждом шоте: эмоции, развороты, взгляды, хват | камеру |

Одна генерация Seedance 2.5 покрывает одну **секвенцию**: несколько шотов подряд, от 4 до 30 секунд, со склейками внутри. Ни ключевых, ни стартовых кадров нет.

## Скилы

| Скил | Что делает |
|---|---|
| `toon-setup` | Проверяет MCP и ffmpeg, пишет паспорт `toon.yaml`, сканирует .blend, заводит Archcore. В нём лежат общие скрипты и справочники |
| `toon-bible` | Импортирует и проверяет листы персонажей и фоны, загружает их в Higgsfield, пишет карточки. Недостающее генерирует только по просьбе |
| `toon-episode` | Превращает сценарий в сцены и список шотов и сверяет его с Blender |
| `toon-grill` | Допрашивает по сцене, по одному вопросу, пока шоты не сойдутся логически |
| `toon-layout` | Проверяет раскладку, предлагает секвенции, выгружает референсы с капсулами, склейками и данными камеры |
| `toon-sequence` | Собирает промпты с таймкодами, считает смету сцены, спрашивает один раз, делает черновики, доводит одобренные до финала |
| `toon-review` | Сравнивает дубль с референсом по шотам и выносит вердикт: одобрено, перегенерировать или переделать раскладку |
| `toon-assemble` | Обрезает дубли по длине и склеивает сцену |

## Установка

Через [skills CLI](https://github.com/vercel-labs/skills), в Claude Code для пользователя:

```bash
npx skills add alloself/toon-skills -g -a claude-code -s '*' -y
```

Или плагином Claude Code. Он заодно подключает MCP Higgsfield:

```
/plugin marketplace add alloself/toon-skills
/plugin install toon-skills@toon-skills
```

Обновление: `npx skills update -g` или через `/plugin`.

## Что нужно

| Что | Как |
|---|---|
| Claude Code | macOS, Windows или Linux |
| Archcore MCP | Плагин Archcore: https://github.com/archcore-ai/archcore |
| Higgsfield MCP | `claude mcp add --transport http higgsfield https://mcp.higgsfield.ai/mcp`, потом `/mcp` и вход. При установке плагином добавляется сам |
| Blender 4.2 и новее | Либо Blender MCP с инструментом, который выполняет Python (например `execute_blender_code`), либо `blender` для фонового запуска. Blender может работать на другой машине, если у обеих есть общая папка |
| ffmpeg, ffprobe, Python 3.8+ | macOS: `brew install ffmpeg` |

## Быстрый старт

В папке проекта:

1. `/toon-setup`: ответь на несколько вопросов, получишь `toon.yaml` и `.archcore/`.
2. `/toon-bible`: импортируй листы персонажей и фоны.
3. `/toon-episode`: вставь сценарий, получишь сцены и шоты.
4. `/toon-grill`: проверь логику каждой сцены.
5. Разложи сцену в Blender:
   - маркеры таймлайна с привязанной камерой, с именами вида `S1_01_лиса_входит`
   - корни персонажей `CHR_*`
   - предметы `PRP_*`

   Другие имена можно перечислить в паспорте.
6. `/toon-layout`: проверь файл, согласуй секвенции, выгрузи референсы.
7. `/toon-sequence`: посмотри смету и промпты, скажи одно «да», получи черновики.
8. `/toon-review` запускается на каждом дубле. Одобри, и `/toon-sequence` сделает финал.
9. `/toon-assemble`: получи склейку сцены.

Первая секвенция идёт **пилотом**. Её генерируют с капсулами и с замороженными болванками, сравнивают рядом, и победитель становится режимом сериала по умолчанию. Решение записывается в ADR в Archcore.

## Кредиты

Ни одна платная генерация не запускается без твоего «да». На сцену приходит одна смета: кредиты по секвенциям, итог, баланс до и после. Внутри одобренной пачки секвенция перегенерируется не больше двух раз без нового вопроса. Каждая задача и её стоимость записываются в журнал сцены.

## Статус

Версия 0.1.0.

**Проверено:** модуль Blender, в фоновом режиме на Blender 5.1, на реальном эпизоде из 207 шотов. Это проверка файла, непрерывность, нарезка на секвенции и референсы с капсулами и склейками. Проверены и обёртки над ffmpeg.

**Пока не проверено:**
- Точные схемы Higgsfield: загрузка медиа, формат элемента `medias`, параметры черновика Seedance 2.5. Скилы читают живую схему перед первой платной генерацией.
- Как Seedance 2.5 воспринимает референс с капсулами. Это покажет пилот.
